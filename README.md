# 🚀 EasySFTP — Простой и современный SFTP-клиент

**EasySFTP** — это современный, быстрый и понятный даже новичку SFTP-клиент с графическим интерфейсом на русском языке в стиле AmneziaVPN и Windows 11.

Никаких 40 кнопок, очередей и перегруженных таблиц. Только то, что нужно: вставил данные сервера и работаешь с файлами как в обычном проводнике.

---

## 🌟 Ключевые возможности

- ⚡ **Вход на сервер в 1 клик**:
  - Если вы уже подключались к серверу ранее, он сохраняется в блоке **«⚡ Недавние серверы»** прямо на стартовом экране.
  - Нажали кнопку **«⚡ Войти в 1 клик»** — и вы мгновенно внутри сервера без повторного ввода паролей и хостов!
- ♾️ **Бесконечное подключение (Keepalive & Auto-Reconnect)**:
  - Автоматическая отправка SSH keepalive пакетов каждые 10 секунд и TCP Keepalive на уровне сокета.
  - Сессия не сбрасывается из-за неактивности (idle timeout) роутеров или файрволов хостинга.
  - Прозрачное автоматическое восстановление соединения при разрывах сети или пробуждении ПК без сброса открытой папки.
- 📁 **Удобное переименование папок и файлов**:
  - Возможность переименовывать любые удалённые папки и файлы по клавише **`F2`**, через контекстное меню или кнопку **«Переименовать»** на панели действий.
  - Автоматическая нормализация путей и сохранение навигации.
- 🎨 **Минималистичный чистый интерфейс**:
  - Аккуратная типографика, гармоничные акценты, отсутствие кричащего визуального шума.
- 👥 **Управление пользователями сервера, мульти-директории и режим песочницы**:
  - Панель администратора: кнопка **«👥 Пользователи и доступ»** в шапке при подключении.
  - **Доступ к нескольким папкам (Multi-Directory)**: администратор может назначить пользователю произвольный список директорий (например, одновременно `/website`, `/uploads` и `/data/media`).
  - 🛡️ **Режим изолированной песочницы (Sandbox)**:
    - Пользователь получает **полную свободу действий** в рамках назначенных ему папок: создание, редактирование, удаление, загрузка любых файлов и подпапок.
    - При этом пользователь **наглухо изолирован от остального сервера** и физически не может выйти за пределы назначенных ему директорий (chroot jail с bind mounts).
  - 👁️ **Режим только для чтения (Read-Only)**: для клиентов и внешних наблюдателей без права изменения.
  - Генерация надёжных паролей в 1 клик (🎲).
  - Удобная кнопка **«📋 Скопировать реквизиты для пользователя»** для быстрой отправки в Telegram или WhatsApp.
  - Автоматическая настройка OpenSSH с автомонтированием в `/etc/fstab` или копирование готового Bash-скрипта.
- 📋 **Умная вставка из AmneziaVPN в один клик**:
  - Скопируйте данные SFTP из AmneziaVPN (или из письма хостинга) и нажмите кнопку **«📋 Вставить настройки из буфера обмена (AmneziaVPN)»**.
  - Программа автоматически заполнит: **Хост (`201.10.73.198`)**, **Порт (`222`)**, **Логин (`sftp_user`)** и **Пароль**!
- 📂 **Чистый проводник файлов (Single-Pane)**:
  - Никакой каши из двух окон и стрелок. При подключении открывается понятный проводник с файлами вашего сервера.
  - Две главные кнопки: **«⬆️ Загрузить файл на сервер»** и **«➕ Новая папка»**.
- ⬇️ **Скачивание и редактирование без лишних действий**:
  - Выберите файл и нажмите **«⬇️ Скачать на компьютер»** — файл сохранится в папку «Загрузки» на вашем ПК.
  - Двойной клик по текстовому файлу открывает встроенный редактор с быстрым сохранением обратно на сервер по **`Ctrl+S`**.
- 🚀 **Встроенный «Учебный демо-сервер (Песочница)»**:
  - Нет сервера или хотите потренироваться? Нажмите **«🚀 Демо-сервер»**, и программа мгновенно подключит вас к безопасной локальной песочнице с примерами файлов. Можно тестировать создание изолированных пользователей и режим Read-Only прямо в песочнице!
- ⚙️ **Наглядная настройка прав доступа (chmod)**:
  - Готовые пресеты («Обычный файл сайта 644», «Папка 755», «Секретный конфиг 600»).
- 💡 **Человеческий перевод ошибок**:
  - Простые понятные объяснения причин сбоев на русском языке.
- ⭐️ **Менеджер серверов (Закладки)**:
  - Сохраняйте адреса своих серверов, чтобы подключаться к ним в один клик.
  - Поддержка как классических паролей, так и защищённых SSH-ключей (`.pem`, `.key`, `id_rsa`, `id_ed25519`).
- 🌓 **Тёмная и светлая темы**:
  - Стильная тёмная тема по умолчанию (приятна для глаз) и чистая светлая тема.
  - Поддержка High-DPI экранов Windows — шрифты всегда чёткие и не размываются.
- ⚡ **Плавная работа без зависаний**:
  - Все операции подключения, скачивания и загрузки работают в фоновых потоках. Окно никогда не показывает `(Не отвечает)`.
  - Удобный прогресс-бар с процентами, скоростью передачи (КБ/с, МБ/с) и кнопкой отмены.

## 🚀 Быстрый запуск

### Способ 1: В один клик (Windows)
1. Дважды кликните по файлу **`start.bat`**.
2. Или дважды кликните по **`EasySFTP.vbs`** (для запуска в чистом оконном режиме без чёрного окна консоли).

### Способ 2: Через командную строку
```bash
python main.py
```

### Зависимости (если запускается на новом компьютере):
```bash
pip install -r requirements.txt
```
*(Используются только стандартный `tkinter` и проверенная библиотека `paramiko`)*.

## 📖 Шпаргалка для новичка

### 1. Что такое SFTP?
**SFTP (SSH File Transfer Protocol)** — это защищённый протокол передачи файлов между вашим компьютером и удалённым сервером. В отличие от старого небезопасного FTP (порт 21), SFTP работает поверх SSH (порт 22) и полностью шифрует весь трафик и пароли.

### 2. Где взять данные для подключения?
При покупке VDS/VPS или хостинга вам на почту приходит письмо с доступами:
- **Хост**: IP-адрес вашего сервера (например: `185.120.45.67`) или привязанный домен (`mysite.ru`).
- **Порт**: стандартный для SFTP — `22`.
- **Логин**: обычно `root` (главный администратор) или `ubuntu`, `debian`.
- **Пароль**: пароль из письма (или файл закрытого SSH-ключа).

### 3. Куда обычно загружают сайты и ботов на сервере?
- `/var/www/html/` — стандартная папка для файлов веб-сайтов (Nginx / Apache).
- `/home/имя_пользователя/` — домашняя папка (удобно для ботов и скриптов).
- `/root/` — домашняя папка администратора root.

### 4. Что значат цифры прав доступа (chmod)?
- **644** — рекомендуется для файлов сайта (`.html`, `.css`, картинок). Владелец может изменять, все остальные — только читать.
- **755** — рекомендуется для папок и запускаемых скриптов.
- **600** — рекомендуется для конфиденциальных данных (пароли в `.env`, SSH-ключи).

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| **Enter** | Войти в папку / Открыть файл |
| **Backspace** | Перейти на уровень вверх (`..`) |
| **F5** | Обновить список файлов |
| **F2** | Переименовать выбранную папку или файл |
| **Delete** | Удалить выбранный файл (с подтверждением) |
| **Ctrl + A** | Выделить все файлы в папке |
| **Ctrl + S** *(в редакторе)* | Сохранить изменения прямо на сервер |
| **Ctrl + F** *(в редакторе)* | Быстрый поиск текста |
